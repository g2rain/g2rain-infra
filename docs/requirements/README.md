# 需求设计与验收模板

涉及公共 API、字典/i18n、数据库、事件、Redis Worker 租约、号段算法或安全边界的需求，应在编码前创建 `docs/requirements/<feature>.md`。

```markdown
# 需求名称

## 状态
草案 / 开发中 / 待验证 / 已完成

## 背景与目标
## 非目标
## 调用方与前置条件
## 主流程、输入与输出
## 业务规则和状态变化
## 权限与安全边界
## 事务、并发、幂等和重试
## 数据、缓存、事件、迁移与回滚
## 异常场景和可观测性
## 验收条件
- [ ] 可测试或可观察的结果
## 测试矩阵
## 发布顺序与文档更新
```

一次只能选择一个明确标记为活动状态的需求进入开发；未决事项不得由实现者自行变成既定规则。
